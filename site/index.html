NO SMOKE AND MIRRORS

What this tutorial demonstrates

Actual WPF interface frames, scripted controls, and sample transcripts and answers. The private demo copy uses isolated I/O, not your desktop, meeting or microphone.

Click guides illustrate control activation; keyboard badges show scripted inputs. They are not a recording of physical mouse movements. Zooms enlarge captured UI, not recreated controls.

Installation, file pickers and provider setup are instructional steps, not footage proving those operations were performed. These examples do not establish screen-sharing compatibility.

Synthetic narration: Microsoft Zira Desktop / Windows System.Speech. No music.

A PHANTOM. NOT A PROMISE OF INVISIBILITY.

Quiet by design.
Honest about the limits.

Phantom Fudge requests Windows capture exclusion. That is not universal invisibility, a security boundary, or a guarantee for every screen-sharing tool. Test your exact sharing setup before relying on it.

Transcription runs locally after explicit Start. Optional answer providers have their own setup and data boundaries. Covering the workspace does not stop recording or answers.
